Open Salamander: Plugins: Delivery Handoff: Reference

Specification Reference

A delivery specification is a UTF-8 JSON file named *.handoff.json (at most 1 MiB). Member names are case-sensitive; $comment members are ignored; unknown members are reported as warnings. Paths are always relative, use /, and are matched case-insensitively.

Top level

handoffSpecFormat version, must be 1 (required).
idStable identifier, lower-case letters, digits, ., _, - (required). Recorded in manifests and used to find the specification during verification.
name, revision, descriptionDisplay name (required), revision label, and description.
variablesValues entered in the build dialog: label, required, default, pattern (regular expression), choices. Built-in variables: date, specId, specName, specRevision.
packagefolderName template (required); outputs (manifestJson, manifestCsv, contents; null disables the last two); contents (title, groupBy folder/rule, notes); limits (maxFiles, maxTotalBytes, maxRelativePathLength); preserveModifiedTime; buildRecord (beside/none); manifest.includeSourcePaths.
namingcharset (portable/unicode), allowSpaces, case (keep/lower/upper), maxNameLength, transliterate, replacement, sourceNameRegex.
contentallowedFormats, forbid globs (default: Thumbs.db, .DS_Store, desktop.ini, ~$*, *.tmp, *.bak, __MACOSX, .git), hidden, system, emptyFiles, maxFileSize, duplicates, unassigned.
formatsCustom formats: extensions, magic signatures (offset with hex or ascii), text, label.
rules1 to 256 rules, evaluated in order (see below; required).
severityFinding code mapped to error, warning, info, or off.
policyallowErrorOverride (default false), requireWarningAcknowledgement (default true).

Rules

id, title, description, roleIdentifier, display title, description, and role (deliverable, source, asset, document, supporting).
required, countWhether the rule must select something, and min/max counts.
selectinclude and exclude globs (*, **, ?, [a-z], {a,b}), nameRegex, pathRegex, shared, and latestRevision (regex with one group, scope name/folder, prefixOrder) to keep only the newest revision.
expectkeyRegex (group 1 is the item key), keys, registerCsv (path, column, optional where), allowUnexpected. Each missing key is reported.
formats, fileSizeAllowed format IDs (pdf, ai, eps, psd, svg, indd, png, jpeg, tiff, gif, bmp, webp, heic, avif, zip, docx, xlsx, pptx, dwg, dxf, ifc, otf, ttf, ttc, woff, woff2, mp4, mov, txt, csv, md, or custom) and size limits such as "200 MB".
pdfversion, pages, pageSizes (A0–A6, B1–B4, Letter, Legal, Tabloid, ARCH-A–ARCH-E, or widthMm/heightMm), orientation, toleranceMm, allPagesSameSize, allowPasswordProtected.
imagewidth, height, longEdge, shortEdge, exact, aspectRatio, dpi, colorModel, alpha, bitDepth, frames, forbidGps.
approvalmode (none, evidence, confirm, evidenceAndConfirm) and evidence (pathRegex, nameRegex, sidecar, registerCsv).
licenserequired, sidecar, registerCsv (file, licence, licensor, expiry, scope columns and allowedScopes), includeEvidence, evidenceFolder, expiryWarningDays.
targetfolder and name templates and keepSubfolders.
severitySeverity changes that apply to this rule only.

Templates

Names and folders use tokens in braces: variables, {date} and {date:yyyyMMdd}, and per file {stem}, {ext}, {name}, {key}, {rev}, {rule}, {relDir}, and {seq}/{seq:000}. Results are cleaned up by the naming policy; a changed name is reported so you can see the original and the new name.
