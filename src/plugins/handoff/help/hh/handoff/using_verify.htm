Verifying a Delivery Package

Verification checks a package before you send it, or after someone else has handled it.

To verify a package:

  1. Focus the package folder (or open it) in a panel and make that panel active.
  2. Open the window:
    Menu:Plugins/Delivery Handoff/Verify Delivery Package...
    If neither the focused folder nor the current folder contains a manifest, choose the package folder.
  3. Read the result: Verified, Verified with warnings, or Failed.

Verification recomputes SHA-256 for every file listed in the manifest and reports missing, modified, and unlisted files. When the build record beside the package is found, the manifest itself is authenticated against it. When the specification used for the build is found (in the build record, the library folder, the recent list, or chosen with Browse), its content, naming, format, PDF, image, and count rules are checked again. A specification that changed since the build is used with a warning. Approvals cannot be re-derived from a package; they are listed as recorded.

Save report writes a plain-text report to a location you choose; reports are never saved inside the package.
