Building a Delivery Package

The Build Delivery Package dialog starts a build session. It opens for the active panel (the working folder) and the inactive panel (the staging folder); both must show folders on a disk or network share, and neither may contain the other.

To build a delivery package:

  1. Open the dialog:
    Menu:Plugins/Delivery Handoff/Build Delivery Package...
  2. Check the Working folder and Staging folder. Swap exchanges them.
  3. Choose the Scope: the entire working folder, or only the items selected in the panel.
  4. Choose the Specification. The list contains specifications from the nearest .handoff folder above the working folder, from the specification library folder (see Configuration), and recently used ones. Browse opens any other file; Validate checks the selected file; Show in panel focuses it so you can edit it (for example with F4).
  5. Enter the Variables. Select a variable and type its value below the list, or choose it from the drop-down list. Required variables are marked.
  6. Check the Package folder preview. It must be available: an existing folder is never overwritten.
  7. Choose Scan. The Review Delivery Package window opens.

When a previous build was interrupted, the dialog offers to remove its unfinished hidden package folders from the staging location. Only folders that no running build is using are offered.
