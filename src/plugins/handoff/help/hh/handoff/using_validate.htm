Validating a Specification

The Validate Specification dialog checks a *.handoff.json file and lists every problem with its line, column, code, and the JSON location it refers to.

  1. Focus the specification file in a panel, or open the dialog and choose Browse:
    Menu:Plugins/Delivery Handoff/Validate Specification...
  2. Edit the file in any text editor, then choose Validate again.
  3. Copy copies the findings as text.

See Specification Reference for the file format.
