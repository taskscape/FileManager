Creating a Specification

New Specification from Template writes a starter specification that you then adapt.

Design studio handoffLogos, brand guidelines (latest approved version), and licensed fonts.
Architecture drawing issueSheet PDFs checked against a drawing register, latest revisions, A1/A3 sizes, DWG and IFC models.
Consultancy report deliveryFinal approved report, appendices, and data files.
Client delivery (example)Approved PDFs, source artwork, licensed assets, and a contents list.

The file is saved in the .handoff folder of the current folder by default (the folder is created if needed). An existing file is never replaced. After saving, the new file is focused in the panel.
