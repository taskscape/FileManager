Getting Started with PictView Plugin

The PictView plugin is an image viewer, converter, and thumbnailer. It is based on the famous freeware PictView (for DOS and Windows) image manipulation program, but it decodes and encodes through the Windows Imaging Component rather than the original PVW32Cnv.DLL engine. It therefore reads and writes the formats Windows itself supports, plus any additional imaging codec installed on the machine (HEIF, WebP, AVIF and camera RAW among them), and no longer covers the long tail of legacy formats the original engine handled.

See File Viewer, Menu Extension and Thumbnail Loader sections in Using Plugins for a description of basic work with plugin viewer, menu extension, and thumbnailer.
