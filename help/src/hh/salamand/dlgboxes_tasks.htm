File Manager: Dialog Boxes

File Manager Task List

Use this dialog to break or terminate a not-responding File Manager task.

Dialog Box Options

List of running File Manager tasks
Contains a list of all File Manager tasks. Current task has "current process" appendix.
Highlight
Flash main window of selected File Manager task.
Break
Breaks selected File Manager task and invokes its Bug Report dialog.
Terminate
Terminates selected File Manager task.
Refresh
Refresh list of running File Manager tasks
